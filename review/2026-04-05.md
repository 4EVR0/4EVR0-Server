# 2026-04-05 — 프로젝트 골격 + `GET /health`

## 오늘 목표

FastAPI WAS 프로젝트의 빈 상태에서 기본 골격을 만들고,
`/health` 엔드포인트가 정상 응답하는 상태까지 구현한다.

---

## 만든 파일 목록

| 파일 | 역할 |
|------|------|
| `requirements.txt` | 프로젝트 의존성 (FastAPI, uvicorn 등) |
| `app/main.py` | FastAPI 앱 진입점 |
| `app/core/config.py` | 환경 설정 (pydantic-settings) |
| `app/core/logging.py` | 로깅 초기화 |
| `app/core/exception_handler.py` | 전역 에러 핸들러 |
| `app/schemas/common.py` | 공통 에러 응답 스키마 |
| `app/api/health.py` | `GET /health` 엔드포인트 |
| `.gitignore` | `__pycache__`, `.env` 등 제외 |

---

## 실행 방법

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

접속: `http://127.0.0.1:8000/health`

---

## API 응답 확인

```json
{
  "status": "degraded",
  "dependencies": {
    "neo4j": "not_connected",
    "postgresql": "not_connected",
    "redis": "not_connected",
    "llm": "not_connected"
  },
  "version": "1.0.0"
}
```

> `degraded`는 정상 — 아직 DB를 연결하지 않아서 그렇다.  
> 모든 의존성이 `"ok"`이면 `"healthy"`로 바뀐다.

## 핵심 개념 정리

### 1. `pydantic-settings` — 설정을 클래스로 관리

```python
# app/core/config.py
class Settings(BaseSettings):
    neo4j_uri: str = "bolt://localhost:7687"

    class Config:
        env_file = ".env"
```

- 클래스 필드가 기본값
- `.env` 파일이나 환경변수로 덮어쓸 수 있음
- 배포 시 코드 변경 없이 환경변수만 바꾸면 됨

---

### 2. `APIRouter` — 기능별 라우터 분리

```python
# app/api/health.py
router = APIRouter()

@router.get("/health")
async def health_check(): ...
```

```python
# app/main.py
app.include_router(health.router)
```

- 기능마다 별도 파일에 `router`를 만들고, `main.py`에서 조립
- 파일이 늘어도 `main.py`가 복잡해지지 않음

---

### 3. 전역 예외 핸들러 — 에러 응답 형식 통일

```python
# app/core/exception_handler.py
async def global_exception_handler(request, exc):
    request_id = str(uuid.uuid4())[:8]
    return JSONResponse(status_code=500, content={
        "error_code": "INTERNAL_SERVER_ERROR",
        "message": "서버 내부 오류가 발생했습니다.",
        "detail": str(exc),
        "request_id": request_id,
    })
```

- 어디서 에러가 터져도 항상 같은 JSON 형식으로 응답
- `request_id`는 로그 추적용 (에러 발생 시 ID로 로그에서 검색 가능)

---

### 4. `HealthResponse` 설계 포인트

```python
all_ok = all(v == "ok" for v in deps.model_dump().values())
status = "healthy" if all_ok else "degraded"
```

- 의존성 중 하나라도 `"ok"`가 아니면 `"degraded"` 반환
- 향후 Neo4j/PostgreSQL ping 로직만 교체하면 실제 헬스체크 완성
