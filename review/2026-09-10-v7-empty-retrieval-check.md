## id 20 — 간헐적 날조 (관측 3회 중 2회)

아래 두 실행에서는 동일하게 날조했다.

```
추천 제품
- 클리오 클린스드 모이스처라이저는 히알루론산과 세라마이드가 함유되어 있어 …
- 이니스프리 그린 티 토너는 항산화 성분인 그린 티 추출물이 포함되어 있어 …
- 라노바 리얼 히알루론산 로션은 고분자 히알루론산이 피부 깊숙이 수분을 공급하여 …
```

제공된 제품 데이터가 **0건**인데 브랜드·제품명을 특정했다. 성분 효능도 제공 데이터
없이 단정했다("히알루론산은 피부 수분 함량을 높여…").

다른 4건과 갈린 지점은 질문에 **부정 조건이나 제약이 없다**는 것으로 보인다.
id 45·46은 제약(비건·무향료·EWG)이 있고, id 18·47은 "무난한/평소 쓸"처럼 범위가
좁다. id 20의 "특별한 고민은 없어요. 매일 쓸 기본 제품"은 모델이 일반 지식으로
답하기 가장 쉬운 형태다. **가설이며 5건으로 확정할 수 없다.**

## 부수 발견 — 한자 누출

id 47 응답에 한자가 섞였다.

```
히알루론산은 피부 수분을牢牢히 잡아 건조함을 예방하는 데 …
                    ^^^^ 牢
```

후속 경로 프롬프트(`_FOLLOWUP_SYSTEM`)에는 "Do NOT use any Chinese characters
(Hanja/漢字); use pure Hangul" 지침이 있는데, 메인 생성 경로에서 이 누출이 났다.
`korean_quality` 차원의 실패 유형이며, 5건 중 1건에서 관측됐다.

검사 방법은 리포트에 `hanja` 필드로 남겼다(정규식 `[一-鿿]`).

## 판단

3장에서 열어둔 선택지 중, **"가드 강화만으로 충분"은 기각된다.** 가드는 효과가 크지만
(5건 중 4건) 모델 순응에 의존하므로 완전 차단이 아니다.

검색 공백 시 동작을 코드 차원에서 정하는 것이 맞다. 우선순위 제안:

1. **검색 결과가 0건이면 생성 자체를 하지 않고 정해진 안내문 반환** — 날조 가능성 0.
   현재 `_compose_user_content`의 "일반적인 추천을 제공해 주세요" 지시가 날조를
   유도하는 쪽이므로, 이 분기 자체를 없애는 것이 근본 대응이다.
2. 되묻기(고민을 구체적으로 물어보기)를 안내문에 포함 — id 20·47 같은 광범위 질문에
   실제로 필요한 응답이다.
3. 폴백 제품군을 별도 정의하는 방안은 데이터 작업이 커서 후순위.

이 변경은 `n_products=0` 케이스의 사용자 경험을 바꾸므로, **기준선 측정 후에** 별도
작업으로 다루는 것이 맞다(지금 바꾸면 전후 비교 기준이 사라진다).
