## 상세 변경 사항

### 1. `Concern` enum (26개)

`concern_map.md` §1 Concern Taxonomy 기준으로 8개 단순 코드에서 26개 세분화 코드로 교체.

| 그룹 | concern_code |
|------|-------------|
| acne | `ACNE`, `COMEDONES`, `PORE_CONGESTION` |
| oil | `ENLARGED_PORES`, `OILY_SKIN` |
| sensitivity | `SENSITIVE_SKIN`, `REDNESS`, `IRRITATED_SKIN`, `ATOPIC_PRONE`, `ROSACEA_PRONE` |
| dryness | `DRY_SKIN`, `DEHYDRATED_SKIN`, `FLAKY_SKIN`, `ROUGH_TEXTURE` |
| barrier | `BARRIER_DAMAGE` |
| pigmentation | `HYPERPIGMENTATION`, `DULLNESS`, `UNEVEN_SKIN_TONE`, `BLEMISHES`, `POST_ACNE_MARKS`, `DARK_CIRCLES` |
| protection | `SUNBURN` |
| aging | `AGING_SIGNS`, `WRINKLES`, `LOSS_OF_ELASTICITY`, `SAGGING_SKIN` |

### 2. `Effect` enum (19개)

`concern_map.md` §2 Effect Taxonomy 기준으로 7개 단순 코드에서 19개 세분화 코드로 교체.

| 그룹 | effect_code |
|------|-------------|
| calming | `ANTI_INFLAMMATORY`, `SOOTHING` |
| barrier | `BARRIER_REPAIR` |
| hydration | `HYDRATING`, `MOISTURE_RETENTION` |
| acne_oil | `SEBUM_REGULATION`, `ANTIMICROBIAL`, `PORE_MINIMIZING` |
| acne_exfoliation | `KERATOLYTIC`, `COMEDOLYTIC`, `EXFOLIATING` |
| repair | `SMOOTHING`, `WOUND_HEALING` |
| pigmentation | `DEPIGMENTING`, `BRIGHTENING` |
| protection | `ANTIOXIDANT`, `PHOTOPROTECTIVE` |
| aging | `ANTI_AGING`, `FIRMING` |

### 3. 동의어 테이블 (`_CONCERN_SYNONYMS`)

26개 concern 각각에 대해 한국어 자연어 키워드를 매핑.
- 긴 키워드 우선 매칭 (`sorted(..., key=len, reverse=True)`) 으로 오버매칭 방지
- 형태소 변형 커버: "당기" / "당김" / "당겨" 등 활용형 포함

### 4. `CONCERN_EFFECT_MAP`

기존 `dict[Concern, Effect]` (단일 effect) → `dict[Concern, list[Effect]]` (다중 effect 리스트)로 변경.
`concern_map.md` §3 Concern → Effect 매핑 완전 반영.

### 5. `infer_effects` 함수

다중 effect 리스트를 순회하도록 수정. 중복 제거 후 추론된 effects 반환.
