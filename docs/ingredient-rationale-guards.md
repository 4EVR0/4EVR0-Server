# 성분 추천 근거 보호 (#114, #115)

## 범위

- `LINALOOL`, `FARNESOL`, `LIMONENE`을 긍정 추천 근거에서 제외한다.
  검색 LIMIT 이전, 제품별 근거 재조회, 고민 요약 개수와 핵심 성분, 이전 세션의 매칭 성분에 적용한다.
  해당 성분을 포함한 제품 자체 또는 전성분 사실을 일괄 삭제하지 않는다.
- 생성된 성분 설명의 주요 효능 표현을 성분별 제공 claim 및 검토된 설명 카드와 대조한다.
  다른 성분의 효능을 빌려오거나 제공되지 않은 효능·최상급 표현을 말하면 기존 grounded fallback을 사용한다.
  서버가 추천 제품 부분을 작성하는 모드에도 적용하며, 스트리밍 본문은 검증 뒤에 전송한다.
- 캐시 네임스페이스 v14로 이전 응답 재사용을 막는다. 기존 Redis 데이터는 삭제하지 않는다.

## 한계

정규식과 명시적인 효능 그룹으로 구성한 제한된 검사다. 모든 한국어 동의어·작용기전·부정문·함량·연구 결과를 검증하는 의미 판정기가 아니다.
예를 들어 부정문이나 여러 성분이 섞인 문장은 보수적으로 fallback할 수 있다. 실제 GPU 표적 평가에서 과잉 차단과 누락을 측정해야 한다.
주름/노화, 색소/톤 같은 그룹은 서비스의 효능 표현 묶음이지 임상적 동등성의 증명이 아니다.
데이터에 잘못 적재된 claim 자체는 이 검사로 고치지 못한다. GraphRAG 근거 감사는 별도 유지한다.
검토된 연구 템플릿은 일반 생성 텍스트 검사 대상과 구분한다.

## 검증 및 병합 주의

전체 pytest, 레티놀 미백 문장의 동기/스트리밍 요약 모드 fallback, 향료 근거 요약 제외를 검증한다.
운영 그래프에는 쓰지 않고 실제 조회 두 경로의 필터만 확인한다.
#113 작업과 `neo4j_client.py`의 성분 조회, `recommend_service.py`가 겹칠 수 있다.
#113 병합 시 `$rationale_exclusions` 필터/파라미터 및 본문 grounding 호출을 유지한다.

## 롤백

이 작업의 코드 커밋을 revert한 이미지를 배포한다. DB 변경은 없어 데이터 복원이 필요 없다.
롤백 버전에서도 캐시 prefix는 v14보다 새로운 별도 값으로 지정하여 예전의 문제가 있는 응답을 다시 읽지 않도록 한다.
